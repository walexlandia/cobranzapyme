# Checklist de selección de pymes piloto

## Condiciones mínimas

- [ ] Vende principalmente a empresas medianas o grandes.
- [ ] Emite aproximadamente 20–300 facturas B2B al mes.
- [ ] Usa OC, HES, portales u otros procesos formales.
- [ ] No tiene un equipo especializado de cuentas por cobrar.
- [ ] Puede entregar al menos 6–12 meses de datos históricos anonimizados.
- [ ] Designa a una contraparte con capacidad de decisión.
- [ ] Autoriza por escrito el alcance del piloto y los canales.
- [ ] Acepta registrar trabajo manual y resultados, incluidos los casos sin éxito.

## Preferencias para el primer grupo

- [ ] Existen pagadores compartidos entre dos o más pymes.
- [ ] Hay facturas nuevas y vencidas durante la ventana del piloto.
- [ ] La cartera no depende de un único caso excepcional.
- [ ] La empresa conoce una línea base aproximada de DSO y pago a tiempo.
- [ ] Puede entregar documentos y resolver excepciones con rapidez.

## Exclusiones

- Cobranza a consumidores.
- Cartera principalmente judicial o con disputas comerciales graves.
- Empresa sin autorización para compartir los datos requeridos.
- Expectativa de automatizar portales o SII como condición de entrada.
